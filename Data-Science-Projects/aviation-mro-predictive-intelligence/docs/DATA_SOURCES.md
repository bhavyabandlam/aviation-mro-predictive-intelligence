## Source A — NASA C-MAPSS Turbofan Engine Degradation Simulation (FD001)

- **Source ID:** `nasa_cmapss_fd001`
- **Title:** Turbofan Engine Degradation Simulation Data Set (FD001)
- **Official landing page:** https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/
  (entry #6 "Turbofan Engine Degradation Simulation")
- **Direct download URL:** https://phm-datasets.s3.amazonaws.com/NASA/6.+Turbofan+Engine+Degradation+Simulation+Data+Set.zip
- **Dataset file name / format:** `6. Turbofan Engine Degradation Simulation Data Set.zip` (ZIP, 12,429,152 bytes)
- **Retrieval date/time:** 2026-11-11T19:53Z (UTC)
- **Version / reporting period:** 2008 (PHM08 conference dataset); no explicit version tag
- **SHA-256 checksum (outer archive):** `C9C5DEC12A945A82E8BB4446589D7FB3CC057B5E5D81FA1A12E25EE9912AD3B2`
- **Publisher:** NASA Ames Research Center, Prognostics Center of Excellence (PCoE)
- **Original authors:** A. Saxena, K. Goebel, D. Simon, N. Eklund
- **Citation:**
  > A. Saxena, K. Goebel, D. Simon, and N. Eklund, "Damage Propagation Modeling for Aircraft Engine Run-to-Failure Simulation," in *Proceedings of the 1st International Conference on Prognostics and Health Management (PHM08)*, Denver CO, Oct 2008.
- **Licence / terms status:** Public domain / NASA data. Repository states: "Users employ the data at their own risk. Neither NASA nor the donators of the data sets assume any liability for the use of the data." No formal licence file was shipped in the archive.
- **Known limitations:**
  - Synthetic data generated by the C-MAPSS simulation model, not physical engine measurements.
  - Single operating condition (Sea Level, op_setting_3 = 100.0) and single fault mode (HPC Degradation) — not representative of a full fleet mix.
  - Data is contaminated with sensor noise by construction.
  - True RUL values for the *test* set are provided (RUL_FD001.txt); the test trajectories are truncated before actual failure.
  - Several sensor channels are constant across the whole dataset (non-informative).
- **Local storage path:**
  - Archive: `data/raw/6. Turbofan Engine Degradation Simulation Data Set.zip`
  - Extracted FD001: `data/raw/fd001/`
- **Parser/loader used:** `src/profile_fd001.py` — `numpy.loadtxt` with no header assumption; 26 whitespace-delimited numeric columns.
