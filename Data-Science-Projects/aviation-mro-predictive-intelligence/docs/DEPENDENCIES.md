# Dependencies and Licensing

This document records why each dependency is required (SRS §12 "Dependency and
licence review") and separates **code licensing** from **dataset licensing**.

## 1. Code license

The original source code in this repository is licensed under the **MIT License**
(see [`LICENSE`](../LICENSE)). Third-party packages retain their own licenses.

## 4. Dataset licensing (NOT covered by the MIT code license)

Datasets are governed by their own terms and are **not** licensed under this
repository's MIT license. Full details, retrieval dates, checksums and citations
are in [`DATA_SOURCES.md`](DATA_SOURCES.md).

| Dataset | Character | Terms (summary) |
|---|---|---|
| NASA C-MAPSS FD001 (DS-01/DS-02) | Simulated engine run-to-failure | Cite NASA and original authors; review PCoE repository terms and dataset-specific restrictions before redistribution |
| NASA N-CMAPSS (DS-03) | Simulated, optional | Deferred; inspect its own README/schema/citation before use |
| BTS TranStats / Airline Information (DS-04/DS-05) | Public reported operational data | Deferred; check the selected product's documentation and terms |
| OurAirports (DS-06) | Public airport reference data | Public domain per source; no accuracy/fitness guarantee |
| Synthetic MRO data (DS-07) | Project-generated | Generated by this project under the MIT license; must be labelled synthetic |

## 5. Policy

- Never commit third-party raw data without confirming redistribution rights.
- Prefer scripts/instructions that let users download source data themselves.
- Store citations and retrieval metadata alongside every imported dataset.
- NASA FD001 remains the primary external dataset; synthetic MRO data remains the
  business-analytics dataset; N-CMAPSS is optional; BTS and OurAirports are
  deferred and are not mandatory dependencies.
